# Short Submission Brief (Personalise Before Sending)

**Project:** MarketLens — Real Estate Product Lab  
**Demo:** [Paste the deployed URL after publishing]

I built MarketLens as an independent product case study for a multi-market property marketplace. It turns synthetic marketplace data into a working view of the search-to-qualified-lead funnel, compares five MENA markets, flags listing-quality issues and lets a reviewer model an A/B test for improving qualified enquiries. The prototype highlights how Cairo, Riyadh and Dubai can have different constraints, so I would not ship one generic solution across all markets. It uses generated demo data rather than Property Finder data, and it has not had external users yet. The biggest limitation is that the data is weekly aggregate, so it can surface hypotheses but cannot prove causality; the next step would be event-level validation and a powered market-specific experiment.
