FROM INSIGHT TO IMPACT EXPERIMENT DESIGN

Don't ship opinions.
Test the hypothesis.

Model the potential impact of improving listing-view → lead conversion.

SIMULATION MODE No live traffic or systems connected
01 / DEFINE THE TEST

Listing detail contact-flow test

A lightweight experiment designed to reduce friction at the moment of intent.

PROPOSED A/B TEST
◎
HYPOTHESIS

If we make the contact action clearer and reduce avoidable form friction, more high-intent listing viewers will become qualified leads.

CONTROL · A
Current contact flow

Existing contact CTA and enquiry form. No change to the seeker journey.

BASELINE
TREATMENT · B
Intent-first contact flow

Prominent call / message choice, fewer required fields and context pre-filled from the listing.

VARIANT
PRIMARY METRICQualified leads / listing views
GUARDRAIL METRICSUnqualified rate · response SLA · spam rate
RANDOMISATION50 / 50 seeker-level split
DURATION2–4 weeks, then review power
02 / MODEL THE UPSIDE

Impact simulator

Change the assumed relative lift and see the monthly outcome.

ILLUSTRATIVE MODEL
+10%
+1%+25%
Model: monthly listing views × current view-to-lead rate × assumed relative lift × qualified-lead rate. Assumes traffic and lead quality stay constant; it is not a forecast.
03 / RUN IT PROPERLY

Before calling it a win.

1
Validate the event

Confirm listing view, CTA click, submitted lead and qualified status are deduplicated and timestamped.

2
Check sample size

Calculate the minimum detectable effect using the real baseline rate and eligible traffic.

3
Read the guardrails

Reject a conversion lift if spam or unqualified leads rise, or agent response deteriorates.

4
Roll out by market

Ship only where the treatment wins; do not assume one market's result transfers to another.

DECISION RULE

What would change my mind?

Ship only when the treatment improves qualified leads per 1,000 listing views with a statistically credible result and no material guardrail regression.

✓
SuccessPrimary metric up; guardrails stable.
×
Stop / iterateRaw leads rise but lead quality falls.
